# RabTech Academy Task 2 — Submission bundle

Included:
1. `KPI_Dictionary_Retail_Orders.xlsx` — KPI definitions and ownership/cadence.
2. `Retail_Data_Quality_Profile.ipynb` — executable pandas notebook.
3. `Retail_Data_Quality_Contract.md` — thresholds, actions, escalation, and sign-off.
4. `README.txt` — setup and publishing steps.

## Before submission
1. Download the two official CSVs from the Task 2 page:
   - https://rabtechacademy.in/starter-files/data/retail-orders-raw.csv
   - https://rabtechacademy.in/starter-files/data/retail-data-dictionary.csv
2. Put `retail-orders-raw.csv` next to the notebook.
3. Install dependencies if needed: `pip install pandas numpy jupyter openpyxl`
4. Open the notebook in Jupyter / Google Colab and run all cells. Review column mapping and confirm assumptions against the official data dictionary.
5. Upload the spreadsheet, notebook, contract, and generated CSV outputs to a public GitHub repository (or another publicly accessible location).
6. Test the public link in a private/incognito browser before submitting it to RabTech Academy.

Note: The CSV files are not bundled here because this environment could not fetch the official source files. Use the official task links above; do not replace the starter dataset with invented data.
